# austin-water-quality-analysis
Exploratory data analysis of Austin water quality sampling data using R with a primary focus on three chosen parameters.
## Overview
This project uses water-quality sampling data from the City of Austin Data Portal to explore water conditions across natural water bodies in the Austin area, including creeks, lakes, and aquifers. The exploratory data analysis investigates the following parameters: water temperature, E. coli bacteria, and dissolved oxygen, examining how these measurements vary across locations and over time.
